Create a new shared doc

Creator only. One free, one-time setup — then creating docs takes seconds.

To create Docs from this page, Google requires your own free OAuth Client ID. There is no universal one an app like this can ship — Google ties it to your account and to the web address this page lives at. It costs nothing, works with a free Gmail account, and you only paste it here once per session. People who just edit via your link never need it.

Get your free Client ID (about 5 minutes)
  1. Go to console.cloud.google.com, sign in with your free Google account, and create a new project (any name, e.g. “Voice Doc”).
  2. Open APIs & Services → Library and enable two APIs: Google Drive API and Google Docs API.
  3. Open APIs & Services → OAuth consent screen, choose External, fill in an app name and your email, and save. If it asks for test users while the app is in “Testing,” add your own email.
  4. Open APIs & Services → Credentials → Create credentials → OAuth client ID. Application type: Web application.
  5. Under Authorized JavaScript origins, add the web address of this page — the scheme + domain you opened it from (for example https://your-site.example, no path). If you run into a mismatch error later, this origin is almost always the cause — copy it exactly.
  6. Create it, copy the Client ID (it ends in .apps.googleusercontent.com), and paste it below.

Kept in this tab's memory only — it is not saved, stored, or sent anywhere except Google's own sign-in.
